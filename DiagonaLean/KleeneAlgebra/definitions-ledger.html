Kleene algebra with commutativity: definitions behind the final theorems

De Amorim, Zhang and Gaboardi, Kleene algebra with commutativity conditions is undecidable (arXiv:2411.15979v1). The main result is that no Turing machine decides equality on T Σ̈ or KΣ̈. This page puts each statement beside the paper’s text, with file and line. It lists every definition the final theorems depend on, except that for layers B to E it lists the main declarations, not every helper. Use Trace on any entry to show only what it depends on.

Main result

theorem not_machineDecidable_termEq_bool   : ¬ MachineDecidable encBool fun i : InstB => Equiv DComm i.1 i.2
theorem not_machineDecidable_kaTermEq_bool : ¬ MachineDecidable encBool fun i : InstB => KAEquiv DComm i.1 i.2

No hypotheses. InstB is a pair of expressions over Bool ⊕ Bool, the doubling of the paper’s Σ = {0, 1}, and encBool is the binary digits of its code, which is injective. There are also _nat versions over ℕ ⊕ ℕ.

Not covered at this level: LΣ̈. The race argument needs an r.e. predicate, and language equality is co-r.e.

How the proof works

A decider for equality would give a decider for “M halts on its own code”, contradicting self_halt_undecidable. From top to bottom, each layer is built from the ones below it.

Other results

Many-one reductions from HALT, in the library’s sense of Undecidable. These rest on the ManyOneReduces convention, and no machine computing these exact reductions is built.

-- The reduction function is named in the statement. Given correct constants B and C:
theorem halt_reducesto_termEq_bool_spec   : HALT ⪯ₘ[reductionB B C] fun i : InstB => Equiv DComm i.1 i.2

-- With no hypotheses:
theorem undecidable_termEq_bool     : Undecidable fun i : InstB => Equiv DComm i.1 i.2
theorem undecidable_kaTermEq_bool   : Undecidable fun i : InstB => KAEquiv DComm i.1 i.2
theorem undecidable_not_langEq_bool : Undecidable (Complement fun i : InstB => pl (mk i.1) = pl (mk i.2))
theorem undecidable_termEq          : Undecidable fun i : Inst => Equiv DComm i.1 i.2
theorem undecidable_kaTermEq        : Undecidable fun i : Inst => KAEquiv DComm i.1 i.2

p ⪯ₘ[f] q means ∀ x, p x ↔ q (f x), and Undecidable p is Nonempty (HALT ⪯ₘ p). The theorems · The reduction · Why it is correct

subC builds a table as long as the code number, so it is primitive recursive but cannot be run on real instances. The {0, 1} theorems use their own race program, and no theorem derives the ℕ ones from them or the reverse. The paper’s claim that T Σ̈_M → T Σ̈ is injective is not proved, because the argument does not need it.
