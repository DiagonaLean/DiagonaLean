Formalizing KA with Commutativity Undecidability

2 November 2026

We formalized in Lean 4 the theorem of de Amorim, Zhang and Gaboardi (arXiv:2411.15979) that Kleene algebra with commutativity conditions is undecidable, with no sorry and only the standard axioms. Along the way we found that the paper's Theorem 6, Corollary 7 and Theorem 9 are false as stated, proved repaired versions, and added a many-one reduction from HALT that the paper does not give.

Results

The headline result is unconditional: no theory between pre-KA provability and the language model is separable from the inseparable pair. All files are under DiagonaLean/KleeneAlgebra/.

Setting

An instance is a pair (e, f) of regular expressions over the doubled alphabet ℕ ⊕ ℕ, where every left letter commutes with every right letter.

  • Provable (e, f): e ≤ f holds in the free pre-Kleene algebra, i.e. it follows from the idempotent-semiring axioms, star unfolding e* = 1 + e e*, and the commutations. There are no induction axioms.
  • ModelLe (e, f): the language of e is contained in the language of f, where a string is a pair of words (left part, right part).
  • Provable implies ModelLe, so a theory S with Provable ⊆ S ⊆ ModelLe covers pre-KA, KA with these hypotheses, and the language model itself.

The source of undecidability is the pair SelfOut true / SelfOut false: machines that halt on their own code with output [true], or with output [false]. No Turing machine decides a set containing the first and disjoint from the second. The proof composes a putative decider with a one-state bit-flip machine and runs the result on its own code.

The repo's Undecidable p means HaltProblem ⪯ₘ p. The paper's method gives a separation reduction instead, so we state the main result with InsepUndecidable p: a reduction sending SelfOut true into p and SelfOut false outside it. Like ⪯ₘ, the reduction must be built from data; ours, kaRed, is an executable Lean function. On a one-state machine it outputs expressions of 258 and 1,743 nodes.

Proof structure

Completeness (left) puts output-1 machines in the theory and soundness (middle) keeps output-0 machines out; together with the diagonal argument they give the main theorem. Soundness plus the new divergent-run lemma gives the HALT reduction.

The HALT reduction

Machine M halts on input w exactly when this inequality fails in the language model:

(init w)r RM*  ≤  Σ* (CM)r + Σ* Σ≠ ρM

Here R_M encodes one machine step, C_M is the set of running configuration words, and ρ_M is an explicit residue whose language is everything. This gives HaltProblem ⪯ₘ Complement ModelLe, so Undecidable (Complement ModelLe) holds in the repo's own sense.

  • M halts. The string recording the run up to the halted configuration has its left part a prefix of its right part, so it avoids the error term. Its last word is a halted configuration, so it is not in C_M. This is the paper's soundness argument (Theorem 15).
  • M runs forever. This case is new. Every string of the left side either follows the actual run, so it has the form (u, u·c) with c a running configuration, which lies in Σ* (C_M)_r. Otherwise it takes a wrong step at some point. Configuration words are prefix-free, so the two sides then disagree at some letter, which puts the string in Σ* Σ^≠ Σ̈* (Lemma 33).

The machine-level statement is Enc.halts_iff_not_pl_le in MachineEncoding/Halting.lean, with the new case in Enc.pl_le_of_forall_running. It does not give HaltProblem ⪯ₘ Provable: for a machine that runs forever, the inequality holds in the model, but neither the paper nor this development settles whether pre-KA proves it.

Departures from the paper

Three stated results are false, and one definition and one proof needed changes. None of these affects the main theorem.

Theorem 6, Corollary 7, Theorem 9False at e = 1*: its language is {ε}, but 1* ≠ 1, shown by mapping into the paper's own Example 1Proved the negations (FiniteLangCounterexample.lean), and proved all three for guarded terms, where every starred subterm is non-nullable (FiniteLangExpansion.lean)

Lemma 34Step (4) needs only ≤, so no reindexing bijection; Lemma 33 must keep its right context, since pre-KA cannot absorb strings to the right of Σ̈*Simplified proof; Lemma 33 stated with a right context
Theorem 16, Lemma 34Typos: s_r R*_M and s_r s′Corrected

Every use of Theorems 6 and 9 and Corollary 7 in the undecidability proof is on finite sums of strings, which contain no star and so are guarded.

Two changes make the reduction an explicit function. The residue ρ of Theorem 16 is no longer an existential: a syntax-directed bound gives ρ_M = Σ̈* · bnd(R_M) · R_M*. And the right-hand side uses all words that decode to the halted output [true], not a single halting word, because list-level configurations may keep blank cells.

What remains open

Everything the paper proves is formalized; the open items go beyond it. Details are in GAPS.md.

  1. A Turing machine computing kaRed. This is the only hypothesis on not_machineDecidable_of_between. kaRed runs as Lean code, but building and verifying the TM that maps encodeBoolTM M to its output is a large, mostly mechanical project.
  2. HaltProblem ⪯ₘ Provable, i.e. Σ⁰₁-completeness. Not in the paper. One route is Smullyan's theorem: an r.e. set that separates effectively inseparable sets is creative. It would need the recursion theorem and an enumeration of pre-KA proofs.
  3. General commutation relations. The language model covers only the doubled alphabet and the no-commutation case; the general case needs trace monoids. The main result does not need it.
  4. Smaller items. Uniqueness of the free algebra's universal map, and the Theorem 6 repair restated for the no-commutation case.
