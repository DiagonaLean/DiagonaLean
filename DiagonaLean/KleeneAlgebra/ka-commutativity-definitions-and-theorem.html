KA with Commutativity: Paper and Lean

2 November 2026 · de Amorim, Zhang, Gaboardi, arXiv:2411.15979 · Lean files under DiagonaLean/KleeneAlgebra/

This page puts the paper's final theorem (Theorem 18) beside its Lean statements, then lists every definition that statement depends on, each in its paper form and its Lean form. The paper uses two-counter machines; the formalization uses single-tape Turing machines, so the machine-level definitions differ in shape but play the same role.

The final theorem

Theorem 18 (Undecidability)

Paper, Theorem 18

Let Σ ≜ {0, 1} be a discrete commutable set. Suppose that we have a diagram of sets in which the language map l : T Σ̈ → L Σ̈ factors through l′ : T Σ̈ → X, where l′ is computable. Then equality on X is undecidable. In particular, equality is undecidable on T Σ̈, K Σ̈ and L Σ̈.

Lean, TM/Undecidable.lean
theorem insepUndecidable_of_between (S : Inst → Prop)
    (h₁ : ∀ i, Provable i → S i)
    (h₂ : ∀ i, S i → ModelLe i) : InsepUndecidable S :=
  ⟨sepReduces_of_between S h₁ h₂⟩

/-- Pre-Kleene algebra with commutativity
    conditions is undecidable. -/
theorem insepUndecidable_provable :
    InsepUndecidable Provable :=
  insepUndecidable_of_between _ (fun _ h => h)
    fun _ h => h.modelLe

theorem insepUndecidable_modelLe :
    InsepUndecidable ModelLe :=
  insepUndecidable_of_between _ (fun _ h => h.modelLe)
    fun _ h => h

theorem not_machineDecidable_of_between
    {enc : Inst → List Bool} {R : SingleTapeTM Bool}
    (hR : ComputesReduction R encodeBoolTM enc kaRed)
    (S : Inst → Prop)
    (h₁ : ∀ i, Provable i → S i)
    (h₂ : ∀ i, S i → ModelLe i) :
    ¬ MachineDecidable enc S :=
  not_machineDecidable_of_sepReduces
    (sepReduces_of_between S h₁ h₂) hR

How they correspond. The paper's X, sitting between T Σ̈ and L Σ̈, becomes a theory S with Provable ⊆ S ⊆ ModelLe. Taking S = Provable is the T Σ̈ case and S = ModelLe is the L Σ̈ case. KA lies in between, because the language model is a Kleene algebra in which the commutations hold.

"Equality on X is undecidable" is stated two ways. InsepUndecidable S is unconditional and synthetic: a reduction built from data sends the inseparable pair into and out of S. ¬ MachineDecidable enc S says no Turing machine decides S, under the hypothesis that some machine computes kaRed. The paper's proof assumes this computability step without proof.

The paper decides equality, by sending ⟨M, n⟩ to ⟨l′(eL + eR), l′(eR)⟩. Lean decides the inequality eL ≤ eR directly, which is the same thing in an idempotent semiring.

The proof, as in the paper

Paper, proof of Theorem 18

Define a computable η: compute the term ρ of Theorem 16 for initial configuration aⁿ b⁰ q̇, and let eL, eR be the two sides of Theorem 16's inequality.

If ⟨M, n⟩ ∈ A, the inequality of Theorem 16 is valid, so eL ≤ eR.

If ⟨M, n⟩ ∈ B, suppose l(eL) ≤ l(eR). Since l(ρ) ≤ l(Σ̈*), l(eL) ≤ l(e′R), which by Theorem 15 forces output 1, a contradiction.

A decider for X composed with η would separate A and B, contradicting Theorem 17.

Lean, TM/Undecidable.lean
def kaRed (M : EncodableTM Bool) : Inst :=
  letI := M.stateEncodable
  letI : DecidableEq M.State :=
    Encodable.decidableEqOfEncodable _
  ((Enc.lhsS M.toSingleTapeTM (encodeBoolTM M)).map
      (dmap Encodable.encode),
    (Enc.rhsS M.toSingleTapeTM true).map
      (dmap Encodable.encode))

-- output 1 ⇒ provable (Theorem 16)
theorem kaRed_pos {M : EncodableTM Bool}
    (h : SelfOut true M) : Provable (kaRed M) := by
  let := M.stateEncodable
  let : DecidableEq M.State :=
    Encodable.decidableEqOfEncodable _
  exact le_map _ (Enc.le_of_outputs h)

-- output 0 ⇒ fails in the model (Theorem 15)
theorem kaRed_neg {M : EncodableTM Bool}
    (h : SelfOut false M) : ¬ ModelLe (kaRed M) := by
  let := M.stateEncodable
  let : DecidableEq M.State :=
    Encodable.decidableEqOfEncodable _
  exact fun hle => Enc.not_pl_le_of_outputs h
    (by decide)
    (pl_le_of_map Encodable.encode_injective hle)

def sepReduces_of_between (S : Inst → Prop)
    (h₁ : ∀ i, Provable i → S i)
    (h₂ : ∀ i, S i → ModelLe i) :
    SepReduces (SelfOut true) (SelfOut false) S :=
  ⟨kaRed, fun _ h => h₁ _ (kaRed_pos h),
    fun _ h hS => kaRed_neg h (h₂ _ hS)⟩

-- a TM-computed reduction transfers inseparability
theorem not_machineDecidable_of_sepReduces
    {enc : Y → List Bool} {p : Y → Prop}
    (r : SepReduces (SelfOut true) (SelfOut false) p)
    {R : SingleTapeTM Bool}
    (hR : ComputesReduction R encodeBoolTM enc r.f) :
    ¬ MachineDecidable enc p := fun hp =>
  selfOut_inseparable (S := p ∘ r.f) ⟨r.pos, r.neg⟩
    (machineDecidable_of_computes_reduction hR
      (fun _ => Iff.rfl) hp)

kaRed is the paper's η. The two letter-renaming lemmas (le_map, pl_le_of_map) do the job of the paper's "find a suitable encoding of the characters of ΣM as binary strings": letters are renamed to natural numbers, which preserves provability and reflects model inclusion. ρ_M is computed from the syntax (see "Residue" below), so kaRed is an executable Lean function.

The three theorems Theorem 18 uses

Theorem 17 (effective inseparability)

Paper, Theorem 17

The following two languages are effectively inseparable:

A ≜ {⟨M, x⟩ | M halts on x and outputs 1}
B ≜ {⟨M, x⟩ | M halts on x and outputs 0}.

(The proof of Theorem 18 only uses that they are computably inseparable.)

Lean, TM/Undecidable.lean
/-- `M` halts on its own code with output `[b]`. -/
def SelfOut (b : Bool) (M : EncodableTM Bool) : Prop :=
  M.toSingleTapeTM.Outputs (encodeBoolTM M) [b]

def Separates (A B S : X → Prop) : Prop :=
  (∀ x, A x → S x) ∧ ∀ x, B x → ¬ S x

theorem selfOut_inseparable {S : EncodableTM Bool → Prop}
    (hS : Separates (SelfOut true) (SelfOut false) S) :
    ¬ MachineDecidable encodeBoolTM S := by
  rintro ⟨D, hD⟩
  let E : EncodableTM Bool :=
    ⟨compComputer D flipTM, Fintype.toEncodable _⟩
  obtain ⟨hpos, hneg⟩ := hD E
  by_cases hE : S E
  · exact hS.2 E (compComputer_seq_outputs
      (hpos hE) flipTM_true) hE
  · exact hE (hS.1 E (compComputer_seq_outputs
      (hneg hE) flipTM_false))

The paper cites this as folklore. Lean proves the computable inseparability that Theorem 18 needs, for the diagonal pair "outputs 1 / outputs 0 on its own code". The proof composes a decider with a one-state bit-flip machine and runs the result on its own code.

Theorem 15 (Soundness)

Paper, Theorem 15

Given a two-counter machine M and a configuration s ≤ TM, suppose that the following inequality holds in L Σ̈M:

sr RM* ≤ Σ*(CM + c1)r + Σ*M Σ≠M Σ̈*M,

where Σ≠M ≜ Σx≠y xl yr. If s →*RM cx, then x = 1.

Lean, TM/Syntax.lean and TM/Theorem15.lean
/-- If M outputs [b] on input with b ≠ a, the
    inequality fails in the language model. -/
theorem not_pl_le_of_outputs {input : List Sym}
    {a b : Sym} (h : M.Outputs input [b])
    (hab : a ≠ b) :
    ¬ pl (mk (lhsS M input) : TD _) ≤
        pl (mk (rhsS M a))

-- the algebraic form, for a run d₀ → … → dₙ
theorem theorem15 (d₀ : Data M) (n : ℕ)
    (hrun : ∀ i < n, ((dstep M)^[i] d₀).Running)
    (hhalt : ¬ ((dstep M)^[n] d₀).Running)
    (t : FreeMonoid (Letter Sym M.State))
    (h : pl (R (wdF d₀) * (RM M)∗) ≤
      pl (sig∗ * (crun M + R t) + err (sigAll : TD _)∗)) :
    wdF ((dstep M)^[n] d₀) = t

Theorem 16 (Completeness)

Paper, Theorem 16

Given a two-counter machine M and some configuration s ≤ TM, we can compute a term ρ with the following property. If s →*RM c1, then the following inequality is valid in pre-Kleene algebra:

s RM* ≤ Σ*M(CM + c1)r + Σ*M Σ≠M ρ.

(The left side should read sr RM*, as in Theorem 15.)

Lean, TM/Syntax.lean and TM/Theorem16.lean
/-- If M outputs [a] on input, lhs ≤ rhs is
    provable in T Σ̈. -/
theorem le_of_outputs {input : List Sym} {a : Sym}
    (h : M.Outputs input [a]) :
    (mk (lhsS M input) : TD _) ≤ mk (rhsS M a)

-- the algebraic form, with an explicit residue
theorem theorem16_le {b : TD (Letter Sym M.State)}
    (hb : FiniteStateLe (RM M) b) :
    ∀ (d₀ : Data M) (n : ℕ),
    (∀ i < n, ((dstep M)^[i] d₀).Running) →
    ¬ ((dstep M)^[n] d₀).Running →
    R (wdF d₀) * (RM M)∗ ≤
      sig∗ * (crun M + R (wdF ((dstep M)^[n] d₀)))
        + err (sigAll∗ * b * (RM M)∗)

The paper's halting configuration c1 becomes haltT M a, the set of all configuration words that decode to "halted with output [a]". A single word is not enough, because a Turing machine's tape may keep extra blank cells.

Definitions

Pre-Kleene algebra

Paper, §2

A (left-biased) pre-Kleene algebra is an idempotent semiring X equipped with a star operation, satisfying the semiring equations and x* = 1 + x · x* ("left unfolding"). x ≤ y means y + x = y. A Kleene algebra additionally satisfies left and right induction.

Lean, PreKleene.lean
/-- An idempotent semiring with a star satisfying
    left unfolding. No induction axioms. -/
class PreKleeneAlgebra (α : Type*)
    extends IdemSemiring α, KStar α where
  protected kstar_unfold (a : α) : a∗ = 1 + a * a∗

The free algebra T X with commutation

Paper, Definition 3 and §2.1

A commuting relation on a set X is a reflexive symmetric relation. T X is the free pre-Kleene algebra over the commutable set X: terms formed with the pre-Kleene algebra operations, where two terms are identified if they can be obtained from each other by the pre-Kleene algebra equations, and commuting symbols may be swapped. It is built as T = T′ ∘ S (Figure 1).

Lean, Free.lean
inductive RExp (X : Type*) where
  | zero | one | sym (x : X)
  | plus (e f : RExp X) | mul (e f : RExp X)
  | star (e : RExp X)

/-- Provable equality: the least congruence with the
    pre-KA axioms and `x y = y x` for `C x y`. -/
inductive Equiv (C : X → X → Prop) :
    RExp X → RExp X → Prop where
  | refl (e) : Equiv C e e
  -- symm, trans, congruence, semiring axioms …
  | unfold (e) :
      Equiv C (star e) (plus one (mul e (star e)))
  | comm {x y} : C x y →
      Equiv C (mul (sym x) (sym y)) (mul (sym y) (sym x))

def FreePreKA (X : Type*) (C : X → X → Prop) : Type _ :=
  Quotient (RExp.setoid C)

Lean builds T X concretely, as syntax modulo provable equality, instead of through the adjunctions of Figure 1. The universal property is FreePreKA.lift.

The doubled alphabet Σ̈

Paper, Definition 12

X ⊕ Y ≜ {xl | x ∈ X} ⊎ {yr | y ∈ Y}, where xl ∼ yr, and left (right) letters commute when the originals do. We abbreviate X ⊕ X as Ẍ. A string over X ⊕ Y is a pair of strings (πl s, πr s); we write s →e s′ if sl s′r ≤ e.

Lean, Doubled.lean
/-- Left symbols commute with right symbols. -/
def DComm : A ⊕ A → A ⊕ A → Prop
  | .inl _, .inr _ => True
  | .inr _, .inl _ => True
  | _, _ => False

/-- The free pre-Kleene algebra `T Σ̈`. -/
abbrev TD (A : Type*) := FreePreKA (A ⊕ A) DComm

/-- Strings over `Σ̈`: pairs of words. -/
abbrev W (A : Type*) := FreeMonoid A × FreeMonoid A

def L : FreeMonoid A →* TD A :=
  FreeMonoid.lift fun a => of (Sum.inl a)   -- u ↦ u_l
def R : FreeMonoid A →* TD A :=
  FreeMonoid.lift fun a => of (Sum.inr a)   -- v ↦ v_r
def ofPair (s : W A) : TD A := L s.1 * R s.2

Σ is discrete in the paper's machine encoding, so only xl ∼ yr matters; DComm is exactly that relation. Reflexivity is not listed, since x x = x x holds anyway.

The language interpretation l

Paper, §2.2

If X is a monoid, its power set PX is a ∗-continuous algebra with 0 ≜ ∅, 1 ≜ {1}, A + B ≜ A ∪ B, A · B ≜ {xy}, A* ≜ ⋃n Aⁿ. The language interpretation l : T X → L X maps a symbol x to {x}.

Lean, Doubled.lean
/-- x_l ↦ {(x, ε)}, x_r ↦ {(ε, x)} -/
def gen : A ⊕ A → SetSemiring (W A)
  | .inl a => single (FreeMonoid.of a, 1)
  | .inr a => single (1, FreeMonoid.of a)

/-- The language interpretation l : T Σ̈ → P(S Σ̈). -/
noncomputable def pl : TD A → SetSemiring (W A) :=
  lift gen gen_comm

The error term

Paper, Theorems 15–16 and §4

Σ is the alphabet, each letter read as xl xr. Σ≠ ≜ Σx≠y xl yr. The error term is Σ* Σ≠ ρ, and Σ̈* is the star of all symbols.

Lean, Representable.lean, SingleStep.lean
def dg (u : FreeMonoid A) : TD A := ofPair (u, u)
def sig : TD A := ∑ a, dg (FreeMonoid.of a)     -- Σ
def sigNe : TD A := ∑ a, ∑ b ∈ Finset.univ.filter (· ≠ a),
  of (Sum.inl a) * of (Sum.inr b)              -- Σ^≠
def err (ρ : TD A) : TD A := sig∗ * (sigNe * ρ) -- Σ*Σ^≠ρ
def sigAll : TD A := ∑ x, of x                  -- Σ̈

Machines and configurations

Paper, Definitions 10–11

A two-counter machine is M = (QM, q̇, ι) with instructions Inc(r, q) | If(r, q, q) | Halt(x). Configurations are strings aⁿ bᵐ q.

ΣM ≜ QM + {a, b, c0, c1}
CM ≜ a* b* QM (running configurations)
TM ≜ CM + {c0, c1} (all configurations)

Lean, TM/Encoding.lean, TM/Theorem16.lean
-- machines: Cslib's SingleTapeTM Sym
inductive Letter (Sym St : Type) where
  | lend | rend                              -- ⊢ ⊣
  | cell (o : Option Sym)
  | head (q : Option St) (o : Option Sym)    -- none = halted

structure Data where       -- a configuration
  state : Option M.State
  l : List (Option Sym)
  h : Option Sym
  r : List (Option Sym)

/-- The word ⊢ rev(l) [q, h] r ⊣. -/
def wd (d : Data M) : List (Letter Sym M.State) :=
  Letter.lend :: (cells d.l.reverse ++
    Letter.head d.state d.h :: (cells d.r ++ [Letter.rend]))

/-- (C_M)_r: right copies of running configurations. -/
noncomputable def crun : TD (Letter Sym M.State) :=
  R (FreeMonoid.of .lend) * (Cr M)∗ * Hr M * (Cr M)∗ *
    R (FreeMonoid.of .rend)

/-- T_a: words decoding to "halted with output [a]". -/
noncomputable def haltT (a : Sym) : TD (Letter Sym M.State) :=
  R (FreeMonoid.of .lend) * (R (FreeMonoid.of (Letter.cell none)))∗ *
    R (FreeMonoid.of (.head none (some a))) *
    (R (FreeMonoid.of (Letter.cell none)))∗ * R (FreeMonoid.of .rend)

The transition term RM

Paper, Definition 13

Each instruction is interpreted as ⟦i⟧ ∈ T Σ̈M, e.g. ⟦Inc(1, q)⟧ ≜ ar a* b* qr, ⟦Halt(x)⟧ ≜ (cx)r. The transition relation is

RM ≜ Σ { ⟦ι(q)⟧ ql | q ∈ QM }.

Lean, TM/Transition.lean
/-- Copy one tape cell. -/
noncomputable def C : TD (Letter Sym M.State) :=
  cpf fun o : Option Sym => Letter.cell o

/-- ⊢ C* (u, v) C* ⊣ -/
noncomputable def ctx (u v : List (Letter Sym M.State)) :=
  ofPair (w [.lend], w [.lend]) * (C M)∗ *
    ofPair (w u, w v) * (C M)∗ * ofPair (w [.rend], w [.rend])

/-- The rewriting rule for state q, scanned symbol h. -/
noncomputable def rule (q : M.State) (h : Option Sym) :=
  match M.tr q h with
  | (⟨wr, none⟩, q') =>
      ctx [.head (some q) h] [.head q' wr]
  | (⟨wr, some .right⟩, q') => …   -- move right
  | (⟨wr, some .left⟩, q') => …    -- move left

/-- Definition 13. -/
noncomputable def RM : TD (Letter Sym M.State) :=
  ∑ p : M.State × Option Sym, rule M p.1 p.2

A step rewrites a small window around the head and copies the rest of the tape with C* on both sides. Lemma 14 is mem_RM: the strings of RM M are exactly the pairs (wdF d, wdF (dstep M d)) with d running.

The residue ρ

Paper, Definition 20, Lemma 21, Theorem 22

A term e is a representable relation on L if, among other conditions, there exists some residue term ρ such that Λr e ≤ Λ Nexte(Λ)r + Σ* Σ≠ ρ for every finite Λ. Theorem 16 says "we can compute a term ρ".

Lean, TM/Syntax.lean
/-- The residue ρ_M = Σ̈* bnd(R_M) R_M*, as syntax. -/
def rhoS : Ex M :=
  mul (mul (star (sigAllS M)) (bnd (rmS M))) (star (rmS M))

/-- The right-hand side Σ*(C_M + T_a)_r + Σ*Σ^≠ρ_M. -/
def rhsS (a : Sym) : Ex M :=
  plus (mul (star (sigS M)) (plus (crunS M) (haltS M a)))
    (mul (star (sigS M)) (mul (sigNeS M) (rhoS M)))

/-- The left-hand side (init input)_r R_M*. -/
def lhsS (input : List Sym) : Ex M :=
  mul (rS (wd (initData input : Data M))) (star (rmS M))

bnd is a syntax-directed upper bound on the states of the automaton of a term (Definition 25), so ρ_M is computed from R_M's syntax. Each …S expression is proved equal to its algebraic counterpart (mk_rmS, mk_rhsS, …). Definition 20 is restricted to Λ ⊆ L, since that is all Lemma 34 can supply.

Instances and the undecidability notions

Paper, Theorems 17–18

Objects are encoded as natural numbers ⟨x⟩. Equality on X is decidable if there is a decider d : Σ* → {0, 1} for X= ≜ {⟨x, y⟩ | x and y encode the same element of X}. Two sets are computably inseparable if no total computable function distinguishes them.

Lean, Synthetic/Definitions.lean, TM/Undecidable.lean
-- the library's notion: a Turing-machine decider
def MachineDecidable (enc : X → List Bool)
    (P : X → Prop) : Prop :=
  ∃ D : SingleTapeTM Bool, TMDeciderFor D enc P

/-- An instance: two expressions over ℕ ⊕ ℕ. -/
abbrev Inst := RExp (ℕ ⊕ ℕ) × RExp (ℕ ⊕ ℕ)

def Provable (i : Inst) : Prop :=
  (mk i.1 : TD ℕ) ≤ mk i.2
def ModelLe (i : Inst) : Prop :=
  pl (mk i.1 : TD ℕ) ≤ pl (mk i.2)

structure SepReduces (A B : X → Prop) (p : Y → Prop) where
  f : X → Y
  pos : ∀ x, A x → p (f x)
  neg : ∀ x, B x → ¬ p (f x)

def InsepUndecidable (p : Y → Prop) : Prop :=
  Nonempty (SepReduces (SelfOut true) (SelfOut false) p)

The paper uses the alphabet Σ = {0, 1} and encodes each machine's letters as binary strings. Lean uses ℕ ⊕ ℕ letters and renames each machine's letters by their Encodable codes; the effect is the same.

Beyond the paper: a HALT reduction

The library's own notion, Undecidable p := Nonempty (HALT ⪯ₘ p), needs a reduction that is also correct for machines that never halt. The paper gives none. Dropping Ta from the right-hand side gives one, but to the failure of model inclusion, not to provability.

Paper

Theorem 19: if equality on X is recursively enumerable, it is Σ⁰₁-complete, so a reduction from HALT exists. The proof cites folklore results from Kuznetsov on effectively inseparable sets and builds no explicit reduction. Lean does not formalize Theorem 19; its HALT reduction targets the failure of model inclusion instead.

Lean, TM/Halting.lean, TM/Undecidable.lean
theorem halts_iff_not_pl_le (w : List Sym)
    {ρ : TD (Letter Sym M.State)}
    (hρ : pl (sigAll : TD _)∗ ≤ pl ρ) :
    Halts M w ↔ ¬ pl (R (wdF (initData w : Data M)) * (RM M)∗)
      ≤ pl (sig∗ * crun M + err ρ)

def haltReduces : HALT ⪯ₘ Complement ModelLe :=
  ⟨haltRed, halt_iff_not_modelLe⟩

theorem undecidable_not_modelLe :
    Undecidable (Complement ModelLe) := ⟨haltReduces⟩
