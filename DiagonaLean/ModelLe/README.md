# `ModelLe`: Language Inclusion with Commutativity
## Problem Statement
Given two expressions `e₁ e₂ : RExp (α ⊕ α)` over the doubled alphabet, in which every left letter `.inl a` commutes with every right letter `.inr b`, is the language of `e₁` contained in the language of `e₂` in the model `TD.pl`, that is, does `e₁ ≤ e₂` hold in `L Σ̈`?
